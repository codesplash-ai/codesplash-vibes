# CodeSplash Vibes

CodeSplash Vibes is a cloud-first Vibe Coding Platform by CodeSplash AI. It is focused on prompt-driven app building with managed account, billing, and AI access flows so users can spend more time building and less time wiring together infrastructure.

This repository is the public release surface for CodeSplash Vibes.

## What CodeSplash Vibes Is

- A cross-platform desktop app for prompt-driven app creation
- A cloud-first product with managed auth, billing, project state, and AI routing
- A simpler workflow for vibe coders who do not want to assemble a local engineering stack before they can start building

## Product Positioning

CodeSplash AI is the flagship all-in-one agentic engineering platform.

CodeSplash Vibes is the focused desktop product for cloud-backed vibe coding workflows.
